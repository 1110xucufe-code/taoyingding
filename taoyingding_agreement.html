量化因子数据订阅服务协议

本协议（以下简称"本协议"）由以下双方签订：

甲方（服务提供方）：陶鹰鼎量化因子数据订阅服务运营方（以下简称"甲方"）

乙方（订阅用户）：通过甲方指定渠道完成订阅并支付费用的自然人（以下简称"乙方"）

乙方在完成订阅支付前，应当仔细阅读本协议全部内容。完成支付即视为乙方已充分阅读、理解并同意接受本协议全部条款的约束。

第一条 服务性质与内容

  1. 甲方提供的服务为量化因子数据订阅服务，属于信息技术服务范畴。服务内容为基于量化模型自动计算输出的因子评分数据，通过微信渠道定期推送给乙方。
  2. 甲方不具备证券投资咨询业务资格，本服务不构成任何形式的证券投资咨询、投资建议、买卖指导或收益承诺。甲方推送的所有内容均为模型计算结果的客观呈现，不包含任何主观投资判断或建议。
  3. 服务具体包括：因子评分排名数据推送、模型历史信号回顾数据。推送频率为每3个交易日一次（单期订阅）或每个交易日一次（全期订阅）。
  4. 甲方有权根据模型研发进展、市场环境变化等因素，对服务内容进行合理调整和优化，并提前通知乙方。

第二条 订阅与付费

  1. 乙方应通过甲方指定的官方渠道完成订阅和支付。具体套餐内容、价格以订阅页面展示信息为准。
  2. 订阅服务自甲方确认收款并开通推送之日起生效，服务期限以所选套餐约定的天数为准。
  3. 首次订阅的用户可享受甲方不定期提供的优惠政策（如赠送额外服务天数等），具体优惠以订阅时页面公示为准。
  4. 服务费一经支付，即表示甲方已开始提供数据服务。除以下情形外，已支付的服务费不予退还：
    1. 甲方因自身原因连续5个交易日以上未能正常推送数据，乙方有权要求按未服务天数比例退款；
    2. 甲方主动终止服务且服务期尚未届满的，应按剩余服务天数比例退款。
  5. 乙方不得以模型表现不及预期、因子评分未带来收益、市场行情波动等非甲方过错原因要求退款。

第三条 用户责任与义务

  1. 乙方确认：其订阅本服务系出于自主的量化研究目的，具备相应的风险识别和承担能力，不会将因子数据作为投资决策的唯一或主要依据。
  2. 乙方应妥善保管其 PushPlus Token 等账户凭证，因乙方保管不善导致的信息泄露或被盗用，由乙方自行承担相应后果。
  3. 乙方应确保其提供的联系方式和身份信息真实有效，如因信息不实导致无法正常接收服务，由乙方自行承担责任。
  4. 乙方因参考本服务数据所做出的任何投资决策，以及由此产生的盈亏结果，均由乙方自行承担全部责任，与甲方无关。

第四条 知识产权与保密

  1. 甲方推送的全部数据内容（包括但不限于因子评分、模型算法逻辑、排名数据、业绩跟踪报告等）的知识产权归甲方所有。
  2. 乙方不得以任何形式将甲方推送的数据内容转发、分享、传播、出售或提供给任何第三方。包括但不限于：微信转发、截图分享、复制粘贴、口头传播、公开发布等。
  3. 每条推送消息包含乙方专属身份标识（包括姓名水印和唯一ID），用于识别信息来源。如甲方发现推送内容被传播至非订阅者，有权追溯信息来源。
  4. 乙方违反上述保密义务的，甲方有权立即终止其服务且不予退款，并保留依法追究其法律责任的权利。如因乙方泄密行为给甲方造成损失的（包括但不限于其他潜在用户流失导致的经营损失），乙方应予以赔偿。
  5. 乙方不得对甲方提供的数据进行反向工程、逆向分析，试图还原模型算法或训练方法。

第五条 风险告知

  1. 量化模型基于历史市场数据训练而成，存在模型失效、策略衰减等固有风险。历史回测表现不代表未来实际收益，过往业绩不具有预示意义。
  2. 回测数据虽已考虑交易成本（含佣金、印花税及冲击成本估算），但实际交易执行中可能存在滑点、流动性不足、涨跌停限制等偏差因素。
  3. 甲方公示的回测数据均基于严格的样本外测试，但仍不能排除因数据质量、市场结构变化等因素导致的不确定性。
  4. 证券市场投资存在本金损失风险，乙方应根据自身财务状况和风险承受能力审慎决策。

第六条 服务中断与免责

  1. 因不可抗力（包括但不限于自然灾害、政府行为、网络故障、第三方推送平台中断等）导致服务暂时中断的，甲方不承担违约责任，但应在条件恢复后尽快恢复服务。
  2. 因国家法律法规或监管政策变化导致甲方需要调整或终止部分服务内容的，甲方应提前通知乙方，并按未服务天数比例退还已收取的服务费。
  3. 因第三方推送平台（如 PushPlus）的服务变更、中断或终止导致推送失败的，甲方不承担责任，但应积极协助乙方通过替代渠道获取数据。
  4. 甲方因系统维护、模型升级等原因需要临时暂停服务的，应提前1个交易日通知乙方。

第七条 服务终止

  1. 订阅服务期限届满且乙方未续费的，服务自动终止。
  2. 乙方有权随时书面通知甲方终止服务，但已支付的服务费按照第二条第4款处理。
  3. 如乙方存在以下行为，甲方有权单方面立即终止服务且不予退款：
    1. 违反第四条保密义务，转发、传播推送内容的；
    2. 利用本服务数据从事违法违规活动的；
    3. 以虚假身份信息订阅或恶意干扰服务正常运行的；
    4. 通过技术手段非法获取、篡改或破坏服务数据的。

第八条 隐私保护

  1. 甲方收集的乙方个人信息（包括微信昵称、PushPlus Token、联系方式等）仅用于提供本协议约定的服务，不会向任何第三方披露或出售。
  2. 甲方应采取合理的技术和管理措施保护乙方个人信息的安全，防止未经授权的访问、使用或泄露。
  3. 服务终止后，甲方将在合理期限内删除乙方的个人信息，但法律法规要求保留的除外。

第九条 争议解决

  1. 本协议的解释、履行及争议解决均适用中华人民共和国法律（不含港澳台地区法律）。
  2. 双方因本协议引起的或与本协议相关的任何争议，应首先通过友好协商解决。
  3. 协商不成的，任何一方有权向甲方所在地有管辖权的人民法院提起诉讼。

第十条 其他

  1. 本协议自乙方完成订阅支付之日起生效，服务期限届满或服务终止时失效（但保密义务和知识产权条款在协议终止后仍然有效）。
  2. 甲方有权根据业务发展需要修订本协议条款，修订后的协议将通过服务页面公示。乙方在续费时应重新确认最新版协议。
  3. 本协议中任何条款被认定为无效或不可执行的，不影响其他条款的效力。
  4. 本协议未尽事宜，由双方另行协商补充。补充协议与本协议具有同等法律效力。
